# 测试与反馈清单

## 测试前

1. 安装 Python 3.12、ffmpeg/ffprobe，并以 editable 模式安装项目。
2. 修改 MCP 配置中的剪映、草稿、工作目录和 ffmpeg 路径。
3. 启动客户端后先要求 Agent 调用 `get_jianying_capabilities`。
4. 不要把真实 API Key、客户素材或未授权视频提交到 Issue。

## 建议测试任务

### 本地视频理解

> 分析这个本地视频，先低成本粗看，告诉我内容结构和三个可剪片段；暂时不要生成草稿。

检查：是否显示分析阶段；是否实际读取代表帧；是否区分可见事实与推断；是否复用缓存。

### 局部复查

> 重点复查 00:20 到 00:35，判断人物动作和画面文字，必要时提高采样密度。

检查：是否只分析指定区间；是否没有重跑整条视频；小字不清时是否只提高局部分辨率。

### 字幕与草稿

> 使用视频字幕生成带黑色描边20的字幕轨，先 dry-run，确认后再创建新草稿。

检查：字幕时间是否合理；是否先试运行；是否转述剪映版本兼容提示；是否未覆盖现有草稿。

### 参考成片

> 学习这个导出视频的镜头节奏和字幕布局，用另一组素材制作类似但不复制内容的草稿。

检查：是否先生成观察结论和剪辑规划；是否把候选区间正确映射为 `source_start/source_duration`。

## 反馈内容

- 客户端与模型，例如 Codex/OpenCode/DeepSeek Harness 和具体模型。
- Windows、剪映版本、Python 版本。
- 视频时长、分辨率、是否带字幕；敏感文件只写概况。
- 使用的 `detail/max_frames/resolution/start/end`。
- 预期行为、实际行为、完整错误信息和可公开的阶段日志。
- Token 或耗时的大致数值。
- 是否能在剪映正常打开生成草稿及人工观察到的差异。

优先提交最小可复现步骤。涉及客户素材时请替换为可公开的短测试片。
